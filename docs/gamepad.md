# Управление с геймпада — движение рядом с машиной пешком

Отдельный режим для «Антилопы»: DualSense (геймпад от PS5) подключается к
станции по Bluetooth, и с него можно вести машину, идя рядом — например,
заводить в бокс или маневрировать в тесноте. Родной пульт при этом не нужен:
станция и так стоит вместо радиомодуля машины и говорит с платой напрямую, а
геймпад — просто ещё один источник управления рядом с Mission Planner.

## Главное — безопасность: мёртвая рука

Оператор идёт рядом с 4×4 на мотор-колёсах, поэтому управление построено на
**мёртвой руке** (dead man's switch): движение разрешено только пока удержан
аналоговый триггер **L2**.

- **Держишь L2** — машина едет: газ с левого стика, руль с правого.
- **Отпустил L2** — газ в ноль. Вперёд это тормозит рекуперацией (как
  отпущенный стик на пульте), а поскольку назад рекуперация ловит через раз,
  дополнительно давится **экстренный мотор-тормоз** — чтобы вставало в любую
  сторону, а не катилось накатом.
- **Выронил пад / разорвалась связь** — источник пропадает, каналы протухают,
  и срабатывает штатный failsafe «Антилопы»: оба тормоза. Станция это не
  изображает, а именно перестаёт слать — пусть сработает защита.

Это **не** авто-арм, как на TX12: без активного удержания триггера машина не
тронется, что бы ни было на стиках.

## Раскладка DualSense

| Орган | Функция |
|---|---|
| Левый стик (вверх/вниз) | газ вперёд/назад |
| Правый стик (влево/вправо) | руль (разводит борта) |
| **L2** (аналоговый триггер) | мёртвая рука — держать, чтобы ехать |
| **R1** | стояночный тормоз (тумблер: нажал — включил/выключил) |
| **круг** | разворот на месте (пока держишь; скорость вращения — правым стиком) |
| **треугольник** | экстренное торможение вручную (пока держишь) |

Раскладку можно переназначить в `config.yaml` (`antelope.gamepad`), имена —
коды evdev (`ABS_Y`, `ABS_RX`, `ABS_Z`, `BTN_TR`, `BTN_EAST`, `BTN_NORTH`).

## Мощность — ползунком, а не передачей

У геймпада своих передач нет. Потолок мощности задаётся **ползунком в панели**
(вкладка «Геймпад»): полный газ на стике = выбранный процент. Пока идёшь рядом
пешком — ставь поменьше. Настройка переживает перезапуск станции.

Для сравнения: у пульта TX12 потолок выбирается тумблером передач, а сами
проценты передач 1/2/3 правятся на вкладке «Движение» → «Проценты передач».
Это разные потолки: с геймпада берётся ползунок, с пульта — передача (станция
знает, кто активный источник, и применяет нужный).

## Подключение по Bluetooth

Драйвер родной ядерный (`hid-playstation`, есть в Raspberry Pi OS Bookworm) —
DualSense появляется как обычный джойстик, ничего доустанавливать для этого не
нужно. Нужна лишь Python-библиотека `evdev` (ставится через `install.sh` /
`requirements.txt`); без неё панель покажет предупреждение, а режим будет
неактивен.

Пара — прямо из панели (без SSH):

1. На геймпаде зажать **PS + Create**, пока подсветка не замигает часто.
2. На вкладке «Геймпад» нажать **«Найти и подключить геймпад»** — станция сама
   поднимет Bluetooth, найдёт пад и подключит его (поиск несколько секунд).
3. Готово — появится «подключён», а стики и триггер оживут в реальном времени.

Кнопка ходит в `bluetoothctl` без sudo: установщик включает службу Bluetooth и
добавляет пользователя станции в группу `bluetooth` (после первой установки
может понадобиться перезагрузка, чтобы группа применилась).

Если хочется вручную по SSH — тот же путь:
```bash
bluetoothctl
scan on          # дождаться "Wireless Controller"
pair <MAC>
trust <MAC>
connect <MAC>
```

Работает и по проводу USB-C — тогда пара не нужна вовсе.

## Про встроенный Bluetooth Pi 4

Встроенный BT делит антенну с Wi-Fi, а у станции на 2.4 ГГц поднята точка
доступа `hostapd`. Их одновременная работа даёт взаимные помехи и рваную связь
с падом. Для управления, где обрыв = торможение посреди шага, надёжнее
**отдельный USB-Bluetooth-адаптер** под геймпад (или провод). Встроенного
хватает для пробы, но не для ответственной работы.
