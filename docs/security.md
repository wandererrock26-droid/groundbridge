# Безопасность: пароль панели и модель привилегий

## Авторизация веб-панели

По умолчанию **выключена** (`auth.enabled: false`), чтобы свежая установка
открывалась сразу. Включается автоматически при задании пароля:

```bash
cd ~/groundbridge
source venv/bin/activate
./scripts/set_panel_password.sh
deactivate
sudo systemctl restart groundbridge
```

Скрипт спрашивает пароль дважды, считает хеш (werkzeug — тот же механизм,
что у Flask) и точечно правит `auth.password_hash` + `auth.enabled: true` в
config.yaml, не трогая остальное.

Свойства:

- Один общий пароль (не многопользовательская система). Сессия — подписанный
  cookie; авторазлогин после `auth.session_timeout_minutes` (по умолчанию 30)
  без активности.
- Пароль хранится **только как хеш**. Задание по SSH, а не из панели —
  чтобы пароль не ходил по сети в открытом виде на этапе настройки.
- Ключ подписи cookie генерируется автоматически и хранится в
  `data/flask_secret.key` (0600) — сессии переживают перезапуск сервиса.
- **Fail closed**: если `auth.enabled: true`, а хеш пустой — панель
  полностью заблокирована с подсказкой, а не открыта «по умолчанию».
- Известное ограничение: у пассивно открытой вкладки с истёкшей сессией уже
  установленный WebSocket продолжит получать статусы до первого действия —
  тогда произойдёт редирект на вход. Новые подключения блокируются сразу.

Отключить авторизацию: `auth.enabled: false` + перезапуск сервиса.

**Обязательно включи пароль**, если панель доступна кому-то, кроме тебя —
особенно при установленном хелпере де-клонирования (кнопка перезагрузки и
сброса SSH-идентичности устройства).

## Модель привилегий: узкие sudoers-хелперы

Сервис работает от обычного пользователя. Всё, что требует root, вынесено в
отдельные скрипты с точечными правилами NOPASSWD (ставит install.sh):

| Хелпер | Что может | Почему это безопасно |
|---|---|---|
| `zerotier-cli` (бинарник) | join/leave/статус ZeroTier | правило только на конкретный путь бинарника |
| `groundbridge-fan-control.sh` | скорость вентилятора | сам находит устройство, принимает только число 0–4 — писать в произвольный файл нельзя |
| `groundbridge-wifi-ap-update.sh` | SSID/пароль точки доступа | работает только с профилем `groundbridge-ap`, имя профиля снаружи не принимается |
| `groundbridge-declone.sh` | сброс ZeroTier ID, SSH-ключей, machine-id, hostname, reboot | вызывается кнопкой панели; включи пароль панели, прежде чем раздавать доступ |

Правила лежат в `/etc/sudoers.d/groundbridge-*` и проверяются `visudo -c`
при установке.

## Чувствительные файлы

Все runtime-файлы — в `data/` (в .gitignore):

- `data/flask_secret.key` — ключ подписи сессий (0600);
- `data/zerotier_state.json` — может содержать Central API-токен (0600);
- `data/*_state.json` — сохранённые настройки панели.

`config.yaml` (с хешем пароля) тоже в .gitignore — в репозитории только
`config.example.yaml` без секретов.

## Сетевая поверхность

Панель (8080), MAVLink (14550/udp) и MediaMTX (8554/8888/8889/8189) слушают
все интерфейсы и рассчитаны на **доверенные сети**: LAN, WiFi-точка Pi,
приватная сеть ZeroTier. Не пробрасывай эти порты напрямую в интернет:
MediaMTX настроен без авторизации путей, а видеопоток и MAVLink не
шифруются. Для удалённого доступа используй ZeroTier.
