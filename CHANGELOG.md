# Changelog

Все заметные изменения GroundBridge. Формат вдохновлён [Keep a Changelog](https://keepachangelog.com/ru/).

## v1.5 — 2026-08-08

**Блок «Подключение Mission Planner»**
- IP и порт разнесены по отдельным полям с отдельными кнопками копирования
  (в MP они вводятся последовательно в разные окна).
- Поле «Локально» показывает РЕАЛЬНЫЕ адреса устройства с бэкенда (новый
  API `/api/net/addresses`, LAN/WiFi отдельно от ZeroTier-интерфейсов) —
  раньше при открытии панели через ZeroTier туда попадал ZeroTier-IP.

**Исправление копирования по HTTP**
- Браузерный clipboard-API работает только на HTTPS; старый запасной путь
  копировал видимый текст поля целиком. Новый механизм всегда кладёт в
  буфер точное значение и подтверждает копирование значком «✓» — починены
  все кнопки «Копировать» в панели.
## v1.4 — 2026-08-08

**Режимы работы станции** (переключатель на главной вкладке панели,
названия настраиваются в `station.mode_labels`):

- **Режим CRSF (виртуальный борт)** — прежнее поведение: Mission Planner /
  джойстик → арбитраж → CRSF по UART, failsafe станции.
- **Режим USB MAVLink (прозрачный ретранслятор)** — для машин с полноценным
  полётным контроллером: Mission Planner (UDP 14550) ↔ USB (ttyACM*) ↔ FC.
  Автоопределение скорости FC (перебор стандартных baud до HEARTBEAT),
  автоопределение адреса MP по первому пакету, автопереподключение при
  обрыве USB, счётчики пакетов в панели. Виртуальный борт, джойстик,
  CRSF/SBUS и failsafe станции в этом режиме не запускаются — за поведение
  при потере связи отвечает сам полётный контроллер.

Переключение сохраняет выбор и перезапускает сервис (~5 сек), панель
возвращается сама. Тумблер SBUS временно скрыт из панели (бэкенд рабочий).
Новая документация: docs/modes.md.
## v1.3 — 2026-08-08

**Живые подсказки UART в панели**
- Подсказки под тумблерами CRSF/SBUS теперь читают актуальные порты из
  config.yaml через API и показывают полную цепочку:
  `/dev/ttyAMA2 (uart2) · TX: GPIO4 / RX: GPIO5 · физ. пины 7 / 29`.
- Зашита карта всех UART Raspberry Pi 5 (uart0–uart4 → GPIO → физические
  пины 40-контактной гребёнки); `/dev/ttyAMA10` помечается как отладочный
  разъём, нестандартные порты показываются как есть.
## v1.2 — 2026-08-08

**WiFi-точка доступа из коробки**
- Регион WiFi (RU по умолчанию, `--wifi-country XX`) и снятие
  rfkill-блокировки применяются ВСЕГДА отдельным шагом установки — без
  этого wlan0 не появляется в системе вообще.
- Точка доступа поднимается по умолчанию при первой установке:
  SSID `groundbridge`, пароль `groundbridge`, autoconnect при каждой загрузке.
- Повторный запуск install.sh НЕ трогает существующий профиль — SSID/пароль,
  изменённые из панели, не сбрасываются. Принудительное пересоздание —
  явными флагами `--wifi-ssid`/`--wifi-password`.
- Новый флаг `--no-wifi-ap`.
## v1.1 — 2026-08-08

Первый публичный релиз GroundBridge.

**Ядро**
- Мост управления: Mission Planner (MAVLink `RC_CHANNELS_OVERRIDE` по UDP) и
  USB-джойстик → арбитраж источников → CRSF (UART, 420000/400000 бод) и
  SBUS (второй UART, опционально).
- Failsafe с режимами hold/mute, настройка из панели, переживает перезапуск.
- Ленивое открытие CRSF-UART: сервис и панель поднимаются даже при
  недоступном/неверном порте, мост переподключается сам раз в секунду.
- Видео: USB-плата захвата или RTSP-камера → ffmpeg → MediaMTX
  (RTSP/WebRTC/HLS), OSD «на лету», автозапуск, тестовая заглушка.
- ZeroTier: join/leave/статус/авто-авторизация по Central API-токену.
- Де-клонирование SD-карты одной кнопкой (ZeroTier ID, SSH-ключи, machine-id).

**Панель**
- Тёмная тема, раздельные CSS/JS-модули, WebSocket-обновления, полностью
  офлайн (без CDN).

**Установка**
- Идемпотентный install.sh: пакеты, venv, UART-оверлеи, MediaMTX, ZeroTier,
  узкие sudoers-хелперы, systemd-сервис.
